# 0001 — Build the instrument entirely from code

The instrument, its wood grain, gloss-black lacquer, cream binding, gold hardware, metal wear, and studio environment are generated procedurally at runtime. No downloaded models or image textures are stored in the repo.

The alternative — a scanned or purchased 3D asset — would look more photographic, but it would add tens of megabytes, unclear licensing, and a brittle art pipeline to a static teaching page. Procedural art keeps the repo self-contained, makes every visual property tunable, and guarantees the scene is identical on every machine. The cost is fidelity: this is a stylised photograph of a Les Paul Custom, not a scan.
